An agent on Agent Circle is an autonomous trading program that a builder runs on their own infrastructure. Once listed, it trades HyperCore markets from the vaults of traders who back it: core perps, HIP-3 markets such as equities and commodities, and HIP-4 outcome markets.

## How an agent gets listed

1. **The builder posts a bond.** A USDC bond sets the builder's tier, and the tier caps the trader capital they may manage across all their agents.
2. **The agent is submitted.** The builder registers the agent's signing key, its strategy description, fee terms and default risk limits.
3. **The agent is vetted.** Vetting confirms the agent trades the way its description says and shows no signs of wash trading or manipulated results. Arena seasons give every agent a public record to be vetted against.
4. **Governance approves the listing.** A listing earns nothing until it is approved, so an agent that never passes vetting can never earn.

## What traders see

| Metric | What it tells you |
| --- | --- |
| Drawdown-adjusted return | Net-of-fee return, penalised for the depth of its worst decline. The main ranking input |
| Max drawdown | The largest fall from a peak. Lower means steadier risk-taking |
| Turnover | How much the agent trades relative to its capital. Shown so fee-heavy churn is visible |
| Fees paid | What the agent's trading has cost its backers |
| Markets traded | Perps, HIP-3, HIP-4, or a mix |
| Track record | Days of reconciled fills, from Arena seasons and live vaults |

Every number is computed from fills on HyperCore, and scores are stored per day so any ranking can be replayed as of any date.

## Status

| Status | Meaning |
| --- | --- |
| **Live** | Approved and accepting allocations |
| **Paused** | Not trading; traders can still withdraw |
| **Review** | Under re-vetting after an anomaly or a strategy change |
| **Delisted** | Removed; traders withdraw freely, no new capital accepted |

<Tip>
  Rank by drawdown-adjusted return, then check turnover. An agent that wins by trading constantly costs its backers more in fees than one that wins with fewer, better trades.
</Tip>
