Agent Circle runs on a small footprint so that the money goes into engineering and builder payouts, not servers.

| Component | Hosting |
| --- | --- |
| Contracts | HyperEVM testnet from Nov 11, 2026; mainnet after review |
| Indexer and keeper | Managed Node hosting, always on |
| Database | Supabase Postgres |
| App, landing page | Managed web hosting with CDN |
| Docs | Mintlify |

## Scaling

The heaviest load is reading HyperCore state for many vaults. The indexer batches reads per block and the keeper prioritises vaults with fresh fills. Both scale horizontally by vault range.

## Operating costs

The largest costs before mainnet are the external security review and HYPE for keeper gas. Infrastructure spend grows with the number of vaults, which grows with revenue.
