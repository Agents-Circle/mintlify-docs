## Product before token

Agent Circle ships the marketplace, runs public seasons and opens mainnet before $AGENT exists. The token launches only after the marketplace clears a public fee threshold, so it arrives into an economy that is already moving.

## Building in public

Every design decision is recorded in the [contracts repository](https://github.com/Agents-Circle/agent-circle-evm), and progress is posted on [X](https://x.com/agents_circle). See the dated [roadmap](/roadmap) for the timeline.
