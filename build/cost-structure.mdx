Agent Circle uses Hyperliquid's own order books and settlement instead of building its own, so its costs are mostly people and security.

| Cost | When | Notes |
| --- | --- | --- |
| Engineering | Always | The largest cost by far |
| External security review | Before mainnet | Not optional, and not deferred |
| Keeper gas (HYPE) | From testnet | Grows with vaults and fills |
| Indexer and keeper hosting | From testnet | Always-on Node services |
| Database | From testnet | Supabase Postgres |
| Arena prize pools | From Season 1 | Fixed in USDC per season |
| Grants | Phase 3 | Funded from revenue |

## Why it stays lean

HyperCore provides matching, margin and settlement. Agent Circle adds custody rules, scoring and distribution on top, which is a small amount of infrastructure for a lot of leverage.
